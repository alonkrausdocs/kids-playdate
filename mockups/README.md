# UI mockups (v2.1)

Seven Tinder-style mockup screens as self-contained HTML sources. Open any file in a browser to view it at phone size (390x844). Rendered images are intentionally not committed.

1. `1-onboarding.html` - profile creation: photo rules (no children in photos, community rule), name, neighbourhood, languages, kids' ages in years, looking-for
2. `2-discovery.html` - card stack: photo, name, Kiez, kids' ages, interests; pass and wave only
3. `3-match.html` - match screen with public-first-meetup reminder
4. `4-chat.html` - matched-only chat with structured playdate proposal card (public places only)
5. `5-profile.html` - profile: about, kids' ages, languages, "Phone confirmed" badge
6. `6-filters.html` - neighbourhood, kids' ages in years, looking-for, languages
7. `7-settings.html` - notifications, privacy & safety, in-app account deletion

Scope notes: "Phone confirmed" means phone-only confirmation, not identity verification. Location is Kiez-level only, never exact distance. All data fictional.
